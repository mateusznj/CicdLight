# CicdLight v1.1.1

## 🇵🇱 Polski

Wersja 1.1.1 usprawnia ręczne odświeżanie danych i dodaje możliwość tymczasowego wyłączania połączeń.

### Najważniejsze zmiany

- Przycisk **Odśwież** natychmiast pobiera aktualne dane. Jeśli trwa już automatyczne odświeżanie, zostaje ono zastąpione nowym żądaniem; interfejs pokazuje komunikat o odświeżaniu.
- Połączenia Azure DevOps i GitHub można wyłączyć i ponownie włączyć w ustawieniach bez usuwania zapisanej konfiguracji.
- Gdy wszystkie połączenia są wyłączone, aplikacja informuje o tym zamiast pokazywać nieaktualne dane.

### Instalacja

Po opublikowaniu pobierz instalator Windows x64 z sekcji **Assets** na stronie [CicdLight v1.1.1](https://github.com/mateusznj/CicdLight/releases/tag/v1.1.1).

## 🇬🇧 English

Version 1.1.1 improves manual data refresh and adds the option to temporarily disable connections.

### Highlights

- The **Refresh** button fetches the latest data immediately. If an automatic refresh is already running, it is replaced with a new request; the UI displays a refreshing indicator.
- Azure DevOps and GitHub connections can be disabled and re-enabled in Settings without removing their saved configuration.
- When all connections are disabled, the app displays a clear status instead of showing stale data.

### Installation

Once released, download the Windows x64 installer from the **Assets** section on the [CicdLight v1.1.1 release page](https://github.com/mateusznj/CicdLight/releases/tag/v1.1.1).
