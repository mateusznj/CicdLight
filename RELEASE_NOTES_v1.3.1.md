# CicdLight v1.3.1

## 🇵🇱 Polski

Wersja 1.3.1 porządkuje ekran konfiguracji połączenia: ma nową nazwę i wszystkie sekcje są zwijane.

### Najważniejsze zmiany

- **Nowa nazwa ekranu:** przycisk **Wybierz pipeline'y** nazywa się teraz **Skonfiguruj monitorowanie**, a pozycja **Pipeline'y** w nawigacji ustawień to **Monitorowanie**, ponieważ ekran obejmuje nie tylko pipeline'y, ale też powiadomienia i repozytoria PR-ów.
- **Harmonijki:** sekcje **Powiadomienia projektu**, **Repozytoria pull requestów** oraz **Pipeline'y i releasy** są zwijane i domyślnie zwinięte.
- **Pipeline'y i releasy osobno:** w każdym projekcie pipeline'y i releasy mają własne zwinięte harmonijki z checkboxem zaznaczającym całą sekcję.

### Instalacja

Po opublikowaniu pobierz instalator Windows x64 z sekcji **Assets** na stronie [CicdLight v1.3.1](https://github.com/mateusznj/CicdLight/releases/tag/v1.3.1). Instalator aktualizuje wcześniejsze wersje.

## 🇬🇧 English

Version 1.3.1 tidies up the connection configuration screen: it has a new name and all of its sections are collapsible.

### Highlights

- **New screen name:** the **Choose pipelines** button is now **Configure monitoring**, and the **Pipelines** item in the settings navigation is now **Monitoring**, because the screen covers notifications and PR repositories as well as pipelines.
- **Accordions:** the **Project notifications**, **Pull request repositories**, and **Pipelines and releases** sections are collapsible and collapsed by default.
- **Pipelines and releases separately:** within each project, pipelines and releases have their own collapsed accordions with a checkbox that toggles the whole section.

### Installation

Once released, download the Windows x64 installer from the **Assets** section on the [CicdLight v1.3.1 release page](https://github.com/mateusznj/CicdLight/releases/tag/v1.3.1). The installer upgrades earlier versions.
